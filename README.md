# Trabalho-faculdade-2semestre

MicroBio - Site Institucional
Site dinâmico desenvolvido como trabalho acadêmico, com foco em uma empresa real: MicroBio. O objetivo do projeto foi criar um site funcional, moderno e responsivo para divulgar os produtos e a história da empresa.
📌 Link do Site
Acesse o site publicado pelo GitHub Pages:
➡ https://welinghtonn.github.io/Trabalho-faculdade-2semestre/pages/home.html

🧾 Sobre a Empresa
A MicroBio surgiu em 2018 com o objetivo inicial em atender a área da saúde na realização de análises microbiológicas.O objetivo principal é oferecer serviços de qualidade com atendimento confiável e próximo.

🛠 Tecnologias Utilizadas
HTML5
CSS3
JavaScript

🧩 Funcionalidades
Página inicial com banner fixo
Seção institucional ("Sobre nós") com a história da empresa
Catálogo de produtos dividido em carrossel
Integração com redes sociais (Facebook, Instagram, WhatsApp e Linkedin)
Botão de contato via WhatsApp fixo
Seção com localização via mapa
Informações de contato visíveis
Layout responsivo para dispositivos móveis
